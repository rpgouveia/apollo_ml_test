# Apollo ML Practical Test — Genetic Syndrome Classification from Image Embeddings

Classification of 10 genetic syndromes from 320-dimensional image embeddings using K-Nearest Neighbors (KNN), comparing **cosine** and **Euclidean** distance under 10-fold cross-validation. Evaluation metrics (Macro F1, Top-k Accuracy, ROC AUC) are implemented manually and validated against scikit-learn in unit tests.

The full analysis, results, and discussion are in the accompanying PDF report.

## Requirements

- Python 3.14+
- Dependencies are declared in `pyproject.toml` (locked in `uv.lock`) and exported to `requirements.txt`.

## Usage

Run the full pipeline from the project root:

```bash
# with uv
uv run python main.py

# with pip (virtual environment activated)
python main.py

# custom data location
uv run python main.py --data-path path/to/mini_gm_public_v0.1.p
```

The pipeline runs, in order:

1. **Data processing** — loads the pickle, flattens the `syndrome_id → subject_id → image_id` hierarchy into a table, and runs integrity checks (missing values, duplicate image IDs, embedding dimension, NaN/Inf values).
2. **Exploratory data analysis** — dataset overview, per-syndrome distribution, class imbalance, and subject consistency checks.
3. **Visualization** — 2D t-SNE projection of the embeddings, colored by syndrome.
4. **Classification** — KNN with k = 1–15, cosine vs. Euclidean distance, under three preprocessing settings (raw data, StandardScaler, L2 normalization), evaluated with 10-fold `StratifiedGroupKFold`.
5. **Final evaluation** — averaged ROC curves for the best cosine and Euclidean models, per-class F1 scores, and a paired Wilcoxon signed-rank test across folds.

All figures and tables are written to `outputs/`. Expect a few minutes of runtime, mostly spent on the cross-validation grid.

## Tests

The manual metric implementations are validated against scikit-learn:

```bash
uv run pytest
```

With pip, install pytest first (`pip install pytest`) and run `pytest` from the project root.

The tests cover AUC with continuous and tied scores, invariance to sample order, edge cases (all-equal scores, perfect separation), Macro F1 (including classes absent from `y_true`), per-class F1, and Top-k accuracy.

## Auxiliary Script

`scripts/compare_roc.py` reproduces the evidence table for the ROC tie-handling fix discussed in the report. It is not part of the main pipeline.

```bash
uv run python -m scripts.compare_roc
```

Run it as a module (`-m`) from the project root so that the `src` package is importable.

## Key Methodological Decisions

- **Subject-level splits.** Some subjects have more than one image. Folds are built with `StratifiedGroupKFold` grouped by `subject_id`, so images of the same person never appear in both training and test sets, which would inflate KNN performance.
- **Model selection by Macro F1.** Given the class imbalance (about 3.3× between the largest and smallest syndromes), the optimal k is selected by Macro F1 rather than accuracy.
- **Distance-weighted voting.** `weights="distance"` avoids arbitrary index-based tie-breaking in the neighbor vote.
- **Single source of truth for predictions.** Top-1 accuracy and F1 are computed from the same ranked predictions, using a stable sort that matches `argmax` tie-breaking.
- **Preprocessing leakage.** Scalers are fit on the training fold only.

All stochastic steps (t-SNE and fold shuffling) use `random_state=42`.
